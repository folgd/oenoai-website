# images/

Drop placeholder/real images here. Filenames are referenced by `index.html`
via `<img class="bg-image" src="images/...">` and are gracefully removed
from the DOM if the file is missing — so the CSS striped placeholder
underneath remains visible until you provide a real photo.

| File             | Used for                                          | Suggested ratio |
| ---------------- | ------------------------------------------------- | --------------- |
| `hero.png`       | Hero full-bleed background (vineyard / dusk)      | 16:9 wide       |
| `producer.png`   | Who We Serve · card I  (vineyard · hand · terroir)| 4:5 portrait    |
| `importer.png`   | Who We Serve · card II (warehouse · crate · light)| 4:5 portrait    |
| `restaurant.png` | Who We Serve · card III (table · candle · glass)  | 4:5 portrait    |
| `profile.png`    | Company · founder portrait (optional)             | 3:4 portrait    |

To swap an image, just save a new file with the same name. No code change required.
